Pokemon Lottery Checker

A private, single-user tool that runs on the owner's own computer. It reads the owner's Gmail inbox to find Pokémon Center lottery result emails and shows which of the owner's accounts won or lost each draw.

It is not a public service: there is no sign-up, and only the owner uses it.

Privacy Policy

Last updated: 30 September 2026

  • What is accessed: the app requests only the read-only Gmail scope (gmail.readonly). It never sends, deletes, or modifies email.
  • What is used: only emails matching Pokémon Center lottery result subjects are read, to extract the recipient address, product, result (won/lost), price and payment deadline.
  • Where data is stored: results and the OAuth token are stored only on the owner's local computer. Nothing is uploaded to any server.
  • Sharing: no data is shared with, sold to, or transferred to any third party. No data is used for advertising.
  • Revoking access: access can be removed at any time from the app ("Disconnect Gmail") or at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
